# Scoreboard Example

Example GitHub Pages website with multiple pages.

## Structure

- `index.html` - Home page
- `scoreboard.html` - Current scoreboard
- `players.html` - Players
- `results.html` - Previous results
- `css/style.css` - Shared styling
- `js/scoreboard.js` - Scoreboard JavaScript

Upload these files to the root of your GitHub repository, keeping the folders intact.
